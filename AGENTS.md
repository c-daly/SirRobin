# Repository instructions

At the start of every Codex run in this repository, before planning, editing,
or running project-specific commands, read `CLAUDE.md` completely.

`CLAUDE.md` is the shared, durable project context. Do not duplicate its
contents here. Treat its architectural principles and working agreements as
guidance, while checking status claims and dated execution authority against
the current repository. Explicit user, system, and developer instructions take
precedence. If `CLAUDE.md` conflicts with current code or a newer project
decision, flag the drift instead of silently following stale text.
